# Solar Panel Efficiency & Output Monitor

## About the Project
The Solar Panel Efficiency & Output Monitor is a Java-based application designed to monitor solar panel conditions and estimate their efficiency based on environmental factors.

## Features
- Select different types of solar panels.
- Enter environmental conditions.
- Estimate dirt accumulation.
- Calculate the next recommended cleaning date.
- Display the panel condition.

## Technologies Used
- Java
- Java Swing
- Object-Oriented Programming (OOP)

## How to Run
1. Download or clone this repository.
2. Open the project in your Java IDE.
3. Compile and run the main Java file.
